## 结论

### ACDC 7-label
1. ⭐ **NA_v2_s0.3 (soft_mask, σ=0.3)** 仍是最优模型：
   - mean_dice = **0.90310**（领先第二名 NA_v2_s0.8 的 0.90192）
   - HD95 = **1.3215**（大幅领先所有其他实验）
   - ASD = **0.4583**
2. NA_v2 系列（soft_mask）整体优于 NA_v1（border_shared）和 NA_v3（border_loss）
3. Mutual 系列中最优为 mw01_7（ACDC原数据集，Dice=0.89711），但 ps=8 后最优为 mw05（Dice=0.89555）
4. BCP_original baseline（BCP baseline）Dice=0.90179，我们的最佳 NA_v2_s0.3 在此基础上提升了 +0.00131

### ACDC label3
- mutual_mw05_ps8 (3 label) → Dice=0.8853
- NA_v2_s0.3_label3 训练中（iter 25,014/30,000, 83.4%）

### LA (BCP_original)
- **BCP_CMC_v1_mutual la8** 最优：Dice=**0.90305**, IOU=**0.82392**
- BCP+CMC mutual 组合在 LA 上优于纯 BCP（la8: 0.89136）和纯 CMC（la8: 0.87177）

### Pancreas (NA_v2)
- **NA_v2_s0.3_20%** Dice=0.8373, Jaccard=0.7226
- **NA_v2_s0.3_10%** Dice=0.8229, Jaccard=0.7017
- 20% 标注数据较 10% 提升显著（Dice +0.0144）
